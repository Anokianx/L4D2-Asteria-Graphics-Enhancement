# Frame input C ABI V1

Author: Anokianx

`AsteriaFrameInputApi.h` is a C-compatible, pack-8 header. Resolve the four undecorated exports from the loaded `AsteriaFrameGenerationLayer.dll` with their declared `PFN_` types; x86 callbacks and exports use `__stdcall`. Structures carry exact `struct_size` and `api_version=1`. Unknown layouts, versions, flags and reserved fields are rejected. Inputs are copied before callbacks, and failure leaves output arguments unchanged.

Register before Vulkan instance/device creation. Registration allows FG device setup when `ASTERIA_FG_ENABLE=1`; it does not establish that real game inputs exist. Only one registration is active. The returned registration ID is not reused. A registration requests two to eight simultaneous leases, bounded across its sessions. Up to sixteen live sessions are accepted.

After successful image acquisition, query the ticket for the exact native device and proxy swapchain. A ticket carries the swapchain generation, next Present input number, image index and successful Acquire serial. Query is unavailable before Acquire or while Present consumes a ticket. More than one outstanding acquired image creates ambiguity and disables inputs until those acquisitions are drained through Present; no association is inferred from arrival order. Resize creates a distinct generation. These IDs do not establish an engine frame number or the contents of a GPU image.

Submit at most one input for that ticket. Pass native `VkImage` bits as `uint64_t`, never FFX boxes or C++ pointers. Depth must be one-mip, single-layer, single-sample 2D `R32_SFLOAT` at the render extent, containing actual normal-Z scene depth. Motion must be `R16G16_SFLOAT` or `R32G32_SFLOAT`, with normalized `previousUV-currentUV`, top-left origin and positive scale `(width,height)`. Both images must be in `SHADER_READ_ONLY_OPTIMAL`, owned by the supplied device and accessible to its configured graphics family. Camera basis, clipping planes, units, FOV and elapsed time must match the input. Declare `Engine` or `Estimated` motion explicitly.

V1 accepts only producer-completed GPU work, scene depth and a HUD-absent color/depth/motion stream. The producer must complete its GPU writes before submission and preserve the images, layout and ownership until the lease release callback. This revision does not import semaphores, queue-family transfers or HUD composition surfaces. `GPU_COMPLETED`, scene identity, image descriptions and HUD absence are producer contract declarations; the bridge cannot independently authenticate them from handle values and flags. A real game producer must qualify these properties separately. Registration and a structurally valid submission are not game-FG readiness evidence.

The lease context and paired retain/release callbacks remain valid throughout submission. Callbacks must not throw. The bridge retains once after structural validation and reservation, and releases once after the final consumer reference retires. A failed submission may retain/release during its call if acquisition, registration or ticket state changes concurrently; the producer must inspect the result. Callback modules are reference-counted before retain and released after the final release callback. Resource release executes outside registry/session locks. Acquired input stays alive across unregistration until consumer completion; pending completed input is released when its session closes.

Live image reservations reject duplicate/reused native handles across sessions and old registrations. The producer must use separate resources while prior inputs remain in flight. The SDK consumer currently waits for its previous presents and GPU work before retirement; this is a conservative serial path. Bounded leases do not implement asynchronous GPU scheduling or a complete resource ring.

Return values distinguish invalid arguments, unavailable state, stale tickets, busy reservations/capacity and internal failures. Unregister when production ends; it stops new sessions and submissions. Callback resources already acquired are still owned until completion. Game FG remains unavailable until a qualified live producer and the complete color/depth/camera/HUD/pacing path have been validated.
